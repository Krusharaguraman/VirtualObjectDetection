# 🚀 Real-Time Object Detection with YOLOv5

## 📌 Project Overview

This project demonstrates a real-time object detection system using a pre-trained YOLOv5 model and OpenCV. It captures video from a webcam, detects objects in each frame, and displays them with bounding boxes and class labels. It's designed for speed, accuracy, and real-world usability.

## 🌟 Key Features

- 🎥 **Live Webcam Feed** – Detects objects from real-time video input
- ⚡ **Fast & Efficient** – Powered by YOLOv5s, optimized for speed
- 🧠 **Deep Learning-Based** – Uses state-of-the-art computer vision models
- 📦 **Multi-Class Detection** – Identifies various object types in one frame
- 📊 **Ready for Extension** – Great starting point for vision-based applications

## 💡 Use Cases

- 🛡️ Surveillance and security systems  
- 🚗 Autonomous vehicles and robotics  
- 🛒 Smart retail analytics  
- 🏭 Industrial automation  
- 🎓 Educational demos and AI research

## 📚 Model Insight

The system utilizes the **YOLOv5s** model — a smaller, faster variant of YOLOv5. It's ideal for applications where real-time performance is critical without sacrificing much accuracy.

## 🎯 Project Goal

This project aims to provide a lightweight yet powerful solution for real-time object detection. It's a practical demonstration of integrating AI with real-world video data and serves as a base for further exploration or deployment in various domains.
